# Root Cause Tracing

이 스킬은 실행 중 깊은 지점에서 나타나는 오류를 근본 원인까지 추적하는 절차를 제공합니다.

## 사용할 때
- 스택이 길고 증상이 입력 지점과 멀리 떨어져 있을 때
- 잘못된 값이 어디서 시작되었는지 불명확할 때
- 특정 테스트/시나리오가 상태를 오염시키는지 추적할 때

## 사용 방법
1. `root-cause-tracing.md`의 절차를 따라 증상 → 직접 원인 → 호출 경로 역추적 → 최초 트리거를 식별합니다.
2. 역추적이 어려우면 스택 트레이스/로그를 추가하고 다시 추적합니다.
3. 테스트 오염이 의심되면 `find-polluter.sh`로 오염 테스트를 찾아냅니다.

## 포함 파일
- `root-cause-tracing.md`: 단계별 절차와 예시
- `find-polluter.sh`: 오염 테스트 탐색 스크립트

## 비고
- 상위 스킬 `systematic-debugging`에서 root-cause-tracing 기법만 분리한 버전입니다.
