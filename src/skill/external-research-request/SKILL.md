# External Research Request (외부 리서치 요청)

## 개요
외부 에이전트(Deep Research, 웹 리서치 도구 등)는 로컬 코드/로그/문서에 접근할 수 없습니다. 이 스킬은 **프롬프트 텍스트만으로 조사 목표를 달성할 수 있도록** 필요한 컨텍스트를 패키징하는 재사용 템플릿을 제공합니다.

## 관련 문서와의 관계
- **이 스킬**: 프로젝트와 무관하게 self-contained 프롬프트를 작성하는 방법론에 집중합니다.
- **`skill/precise_research_prompt.md`**: MEV 프로젝트에서 프롬프트 파일 저장 규칙, PDF 분류, 적용 문서화 규칙을 제공하므로, 해당 문서와 함께 사용하십시오.

## 사용 시점
- 외부 리서치 도구에 조사를 위임해야 하는 경우
- 외부 에이전트가 로컬 파일/로그/코드에 접근할 수 없는 경우
- 공개 문서/SDK/온체인 데이터 기반 조사가 필요한 경우

## 사용하지 않는 시점
- 로컬 코드/로그를 직접 분석할 수 있는 경우
- 내부 분석만으로 결론이 가능한 경우

## 핵심 원칙
1. **자기완결성**: 프롬프트만 읽어도 조사 수행이 가능해야 합니다.
2. **증거 기반**: 모든 주장에 출처(URL/퍼머링크)를 요구하십시오.
3. **범위 제한**: 질문은 3~7개로 제한하고, 목표를 명확히 정의하십시오.
4. **보안 준수**: 키/시크릿/개인정보를 포함하지 마십시오.

## 워크플로우

### 1단계: 조사 목표 정의
- 조사 목적, 성공 기준, 산출물 형식을 먼저 명시하십시오.

### 2단계: 컨텍스트 패키징
외부 에이전트가 로컬에 접근할 수 없으므로 아래 항목을 프롬프트에 **직접 포함**하십시오.

**필수 포함 항목**
- 문제 요약(2~5문장)
- 핵심 지표/메트릭 요약
- 관련 설정 값(환경 변수/파라미터)
- 필요한 경우 코드 스니펫(핵심 부분만)
- 관찰된 동작/증상 요약
- 기술 스택/버전 정보

**포함 금지 항목**
- 로컬 파일 경로 또는 로컬 명령
- 민감 정보(키, 토큰, 계정)
- 전체 로그 덤프(필요 시 요약/발췌 형태로 제공)

### 3단계: 프롬프트 작성
아래 템플릿을 기반으로 작성하십시오.

```markdown
# [조사 제목]

## 1) 역할 정의
- 당신은 [역할/전문 분야] 조사자입니다.
- 모든 주장에 출처(URL)를 포함해야 합니다.

## 2) 배경
[프로젝트/문제 상황 요약 2~5문장]

## 3) 핵심 질문
1. [질문 1]
2. [질문 2]
3. [질문 3]

## 4) 제공 컨텍스트 (Self-contained)
### 4.1 지표 요약
- metric_a: [값]
- metric_b: [값]

### 4.2 설정/파라미터
- PARAM_X = [값]
- PARAM_Y = [값]

### 4.3 코드 스니펫 (필요 시)
```language
[핵심 로직 30~80줄 이내]
```

### 4.4 관찰된 증상
- 증상 1
- 증상 2

## 5) 리서치 범위
- 포함: [공식 문서/SDK/소스코드/논문]
- 제외: [추측, 근거 없는 블로그 등]

## 6) 산출물 요구사항
- 요약 3~7개
- 근거 URL 포함
- 비교표/의사코드 포함(필요 시)
- 추가 검증 절차 제시

## 7) 성공 기준
- [ ] 모든 질문에 답변
- [ ] 모든 주장에 URL 근거
- [ ] 상충 정보는 비교/해석 포함
```

### 4단계: 품질 체크
- [ ] 로컬 파일/명령 언급이 없는가?
- [ ] 질문이 3~7개로 제한되었는가?
- [ ] 지표/설정/코드가 모두 프롬프트 내에 포함되었는가?
- [ ] 산출물 형식이 명확한가?

### 5단계: 결과 분류 및 적용
- 결과를 **CONFIRMED / EXTERNAL INPUT**으로 구분하십시오.
- 적용 대상 파일/모듈을 식별하고 변경 사항을 기록하십시오.

## 품질 체크리스트
- [ ] 모든 주장에 출처가 있는가?
- [ ] 최신 정보(버전/날짜)가 명시되었는가?
- [ ] 모순된 정보는 비교/해석되었는가?
- [ ] 실행 가능한 권고안이 포함되었는가?

## 예시
**Bad**
```
로컬 로그를 확인하고 오류를 분석해 주세요.
```

**Good**
```
오류 코드 0x1234가 12건 발생했습니다.
다음 지표 요약을 기반으로 원인을 조사해 주세요:
- received=12,000
- failed=11,900
```

## 보안 주의
- API 키/개인정보/프라이빗 키를 절대 포함하지 마십시오.
